## `01 / ABOUT ME`

I'm a CS student from Kazakhstan focused on understanding how software works **under the hood** - from CPU instructions and memory management to runtimes, storage engines, distributed systems, and autonomous AI infrastructure.

I don't just use abstractions.

**I build them.**

My goal is to understand the mechanisms behind complex software by designing, implementing, testing, and improving systems from first principles.

---

## `02 / WHAT I BUILD`

My projects usually start with a simple question:

> **How does this actually work under the hood?**

Then I try to build a working version from first principles.

- **Operating Systems** - bootloaders, kernels, memory management and userspace.
- **Virtual Machines & Runtimes** - interpreters, managed execution, garbage collection and JIT compilation.
- **Storage Engines & Databases** - write-ahead logging, MVCC, LSM trees and crash recovery.
- **High-Performance Systems** - low-latency C++, data structures and performance-oriented architecture.
- **Distributed Infrastructure** - synchronization, networking and coordination.
- **Kernel Observability** - Linux internals, eBPF and system-level monitoring.
- **AI Infrastructure** - model serving, inference optimization and autonomous agents.

## `07 / ENGINEERING PHILOSOPHY`

I prefer understanding systems from the bottom up.

Instead of starting with:

> *Which framework should I use?*

I usually start with:

> *What is the framework actually doing?*

That leads me toward projects involving **kernels, runtimes, databases, compilers, networking and distributed infrastructure**.

I value:

- **First principles** - understand the mechanism before relying on the abstraction.
- **Correctness** - reason about edge cases, invariants, failures and recovery.
- **Performance** - measure bottlenecks instead of guessing.
- **Simplicity** - make complex internals understandable without hiding their complexity.
- **Continuous improvement** - build, test, inspect and refine.
